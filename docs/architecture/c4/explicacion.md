# Explicación de VotoEPIS para público no técnico

VotoEPIS es una plataforma digital diseñada para que la Escuela Profesional de Ingeniería de Sistemas elija a sus delegados estudiantiles de manera rápida, secreta y transparente desde cualquier computadora o celular. 

El sistema es utilizado por tres grupos: los **estudiantes votantes**, quienes consultan si están habilitados, emiten su voto una sola vez y revisan los resultados; el **comité electoral**, que carga el padrón, abre o cierra la elección y publica el acta final; y el **auditor**, encargado de comprobar que el conteo sea exacto sin vulnerar el secreto del voto. 

Para funcionar, VotoEPIS se apoya en el **correo institucional** para enviar confirmaciones y prevé consultar datos del **Sistema académico UNSA**.
